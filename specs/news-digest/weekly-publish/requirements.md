# 要件定義: 週次記事の自動生成・公開

> ステータス: 仕様確認中(未実装)

## サマリ
ダイジェスト記事の収集・要約・公開を週1回、毎週水曜にGitHub Actionsで自動実行する。通常はPRレビューを必須とするこのプロジェクトの運用の例外として、この週次記事PRに限り完全自動マージを行う(ai-dev-digestの日次記事と同じ扱い)。情報源リスト・採用基準そのものの変更はこの自動マージの対象外とし、[monthly-review](../monthly-review/requirements.md)で別途人間の承認を必須とする。ユースケース図は省略(下記参照)。

> ユースケース図は、アクターが運営者ひとり(自動実行される週次バッチ処理からの受益者)で、単一の自動処理フローのため省略する。

## 概要
- 機能名: 週次記事の自動生成・公開
- 目的: ダイジェスト記事の収集・要約・公開を週1回(毎週水曜)自動実行する。通常はPRレビューを必須とするこのプロジェクトの運用の中で、この機能に限り完全自動マージを行う根拠と条件を明確にする
- 優先度: 高

## ユーザーストーリー
- 運営者として、人手を介さず毎週決まった曜日に記事が公開されてほしい
- 運営者として、自動公開の範囲・条件を明確にしておき、想定外の公開が起きないようにしたい

## 機能要件

### 実行
- [1] 収集・要約・記事執筆のバッチを週1回、毎週水曜に実行する(根拠: /consultでの決定)
- [2] 実行主体はGitHub Actions(スケジュール実行のワークフロー)とする。[content-selection/requirements.md](../content-selection/requirements.md)のスクリプトで各カテゴリの固定リスト・WebSearchから候補を収集・定量判定し、Claude Code CLIのヘッドレス実行(エージェントの推論)により要約・記事執筆までを1回の実行で行う(ai-dev-digestと同じ実行方式。運営者が既に契約しているClaude Code Pro/Maxサブスクリプションの利用枠内で完結させ、追加の従量課金を避ける)
- [3] 生成した記事はコンテンツファイルとしてリポジトリに追加し、ビルド時に取り込まれる形で配信する(サーバーを持たない静的サイトの構成を維持するため)

### 公開フロー
- [4] 生成した記事はブランチを切ってPRを作成し、CI(テスト等)が成功したら人間の承認を待たずに自動的にmainへマージする(通常のCLAUDE.mdの運用(人間レビュー必須)の例外。根拠: /consultでの決定。ai-dev-digestの日次記事と同じ扱いとする)
- [5] CIが失敗した場合はマージせず、原因を記録して運営者が把握できるようにする(具体的な通知方法は設計で詰める)

## ビジネスルール・制約

### 掲載件数の保証
- [1] [content-selection/requirements.md](../content-selection/requirements.md)の基準を満たすトピックが総合・経済/ビジネスで0件でも、神奈川ローカル・育児の専用枠に1件以上あれば、その件数のまま記事を公開する(スキップしない)。全カテゴリで候補が1件もない週のみ、その週はスキップする
- [2] 選定された個々の候補について要約の生成([content-generation/requirements.md](../content-generation/requirements.md))が失敗した場合、その候補だけを除外し、生成に成功した残りの候補でその週の記事を公開する(1件の生成失敗でその週全体を落とさない)。選定された全候補の生成が失敗した場合、および利用枠の枯渇でその週の生成を続行できない場合は、記事を公開せずその週の実行を失敗として終える

### 自動マージの範囲
- [3] 完全自動マージの対象はこの週次記事生成PRに限る。情報源リストや採用基準そのものの変更([monthly-review/requirements.md](../monthly-review/requirements.md))は対象外とし、別途人間の承認を必須とする(根拠: 週次記事1件の影響範囲は小さいが、情報源・採用基準の変更は以後の全記事の方向性を左右する重い変更のため)

## 依存関係
- 収集対象・採用基準は[content-selection/requirements.md](../content-selection/requirements.md)に従う
- 要約・記事執筆のルールは[content-generation/requirements.md](../content-generation/requirements.md)に従う
- 生成された記事の表示は[article-list/requirements.md](../article-list/requirements.md)・[article-detail/requirements.md](../article-detail/requirements.md)に従う

## スコープ外
- 手動でのタイミング指定実行・即時再実行機能
- 週に複数回の実行
- 実行結果の詳細ログを訪問者向けに公開すること
