# 要件定義: 使い方ガイド

> ステータス: 仕様確認中(未実装)

## 概要
- 機能名: 使い方ガイド
- 目的: 初めて資産推移シミュレーターを開いた利用者や、「差引後余剰」「複利運用」などの専門用語につまずく利用者向けに、画面内で機能説明・チュートリアルを確認できるようにする
- 優先度: 中

## ユーザーストーリー
- 利用者として、各入力・表示カードが何をする場所か分からないとき、その場で説明を確認したい
- 利用者として、初めて画面を開いたとき、収支入力→前提条件設定→資産推移確認という操作の流れをざっと把握したい
- 利用者として、「差引後余剰」「複利運用」など本ツール特有の言葉の意味を、必要なときにいつでも調べられるようにしたい

## 機能要件

### コンテキストヘルプ(？アイコン)
- [1] 以下の各カードのタイトル横に「?」アイコンを表示する: 収入、個人支出、世帯按分、収支サマリー、前提入力、家族構成、貯蓄/運用切替、賞与・イベント、資産推移グラフ・テーブル
- [2] 「?」アイコンをクリック(タップ)すると、そのカードの説明を記したポップオーバーを表示する。もう一度同じアイコンをクリックするか、ポップオーバーの外側をクリックすると閉じる
- [3] 同時に開けるポップオーバーは1つまでとする。別の「?」アイコンを押すと、開いていたポップオーバーは閉じて新しいものが開く
- [4] 各アイコンの説明文言は「ビジネスルール・制約」の「コンテキストヘルプの文言」を初版とする

### 使い方バナー
- [1] 画面上部(タイトルの下)に、操作の流れを案内する折りたたみ式のバナーを表示する
- [2] バナーは初回表示時、開いた状態(3ステップの操作ガイドが見える状態)から始まる
- [3] 3ステップの文言は「ビジネスルール・制約」の「使い方バナーの文言」を初版とする
- [4] バナーはクリックして開閉できる
- [5] バナーの開閉状態はブラウザに保存し、次回以降の訪問時もその状態を維持する(開いたまま次回訪問すれば開いた状態、閉じて次回訪問すれば閉じた状態)

### 用語集
- [1] 資産推移グラフ・テーブルのカード付近に「用語集」ボタンを設置する
- [2] ボタンを押すと、本ツール特有の用語とその説明を一覧表示するモーダルが開く
- [3] 掲載する用語は「差引後余剰」「貯蓄のみモード」「資産運用モード」「マイシナリオ」の4つとし、説明文言は「ビジネスルール・制約」の「用語集の文言」を初版とする
- [4] モーダルは閉じるボタン、またはモーダル外側のクリックで閉じる

## ビジネスルール・制約

### コンテキストヘルプの文言
| カード | 説明文言 |
|---|---|
| 収入 | 手取り月収と、年間の賞与回数・1回あたりの金額を入力します。ボーナス月だけ金額を変えたい場合は「賞与・イベント」で個別に上書きできます。 |
| 個人支出 | 家賃や通信費など自分だけの支出を、年額/月額に分けて登録します。円グラフで支出の内訳がひと目で分かります。 |
| 世帯按分 | 配偶者がいる場合、家賃や光熱費など世帯共通費を按分(分担)した自分の負担額を入力します。 |
| 収支サマリー | 収入から支出を差し引いた「毎月の余剰資金」を表示します。この金額が資産推移の元手として毎月積み上がっていきます。 |
| 前提入力 | シミュレーションの元本となる、今の資産額と開始年月を入力します。 |
| 家族構成 | 配偶者・子どもの生年月を入力すると、資産推移の各時点での年齢を一緒に確認できます(未入力でも計算は行われます)。 |
| 貯蓄/運用切替 | 「資産運用」モードでは想定利回り(年率)を設定でき、複利で運用した場合の資産推移を計算します。 |
| 賞与・イベント | 特定の月だけ賞与額を上書きしたり、結婚・出産などの一時的な支出を登録して資産推移に反映します。 |
| 資産推移グラフ・テーブル | 入力した収支・前提条件をもとに、資産額の推移をグラフと表で確認できます。月次/年次の表示切り替えにも連動します。 |

### 使い方バナーの文言
| ステップ | 文言 |
|---|---|
| ① 収支を入力する | 収入と支出を入れると、毎月の余剰資金が自動で計算されます。 |
| ② 前提条件を設定する | 今の資産額・家族構成・貯蓄/運用モードを選びます。 |
| ③ 資産推移を確認する | グラフとテーブルで将来の資産を確認。賞与やイベントも追加できます。 |

### 用語集の文言
| 用語 | 説明文言 |
|---|---|
| 差引後余剰 | 毎月の余剰資金に、賞与や一時的な支出(イベント)を反映した後、実際に資産へ積み上がる金額です。 |
| 貯蓄のみモード | 運用による増減を考慮せず、元本と余剰資金の積み上げだけで資産推移を計算する表示モードです。 |
| 資産運用モード | 設定した想定利回り(年率)で複利運用した場合の資産推移を計算する表示モードです。 |
| マイシナリオ | ログインした利用者が、入力値一式に名前を付けて保存・呼び出しできる機能です。 |

### 保存できない環境でのフォールバック
- [1] バナーの開閉状態の保存に失敗する環境(プライベートブラウジング等でブラウザ保存が使えない場合)では、初期状態(開いた状態)にフォールバックする。エラー表示は行わない

## 非機能要件・UI/UX要件
- PC(2カラム)・スマホ(1カラム)のどちらでも、ポップオーバー・バナー・用語集モーダルが画面幅からはみ出さないようにする

## 依存関係
- コンテキストヘルプの対象カードは`monthly-balance/requirements.md`(収入・個人支出・世帯按分・収支サマリー)、`asset-projection/requirements.md`(前提入力・家族構成・貯蓄/運用切替・賞与イベント・資産推移グラフ・テーブル)の各カードに対応する
- 用語集の「マイシナリオ」は`saved-scenario/requirements.md`の機能を指す

## スコープ外
- 初回訪問時に画面全体を暗転させ要素を1つずつ説明するスポットライト型のツアー
- 資産推移グラフ・テーブルが未入力のときの空状態ガイド表示
- バナーを「二度と表示しない」ように明示的に選択するUI(開閉状態の自動記憶のみ対応)
- 多言語対応
- 用語集内の検索・目次機能
